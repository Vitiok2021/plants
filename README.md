# Plants

## Опис
"Plants" — сайт, присвячений теплицям та догляду за рослинами. На сайті представлені різноманітні види рослин, рекомендації щодо їхнього догляду, а також поради для тих, хто хоче вирощувати рослини вдома.

## Технології
- HTML5
- SCSS
- JavaScript
- Адаптивна верстка (Flex, Grid)
- Галерея зображень рослин
- Форма зворотного зв'язку

## Демо
[Plants](https://vitiok2021.github.io/plants/) — сайт про теплицю та догляд за рослинами



## Особливості
- Адаптивний дизайн для мобільних пристроїв
- Зручний інтерфейс для перегляду різних рослин та порад по догляду
- Взаємодія з користувачем через форму зворотного зв'язку
